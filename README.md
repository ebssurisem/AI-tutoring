# 생각의 길 — 우리 집 AI 튜터 (나래 선생님)

초등학생이 집에서 하루 10~15분, **정답 대신 질문으로** 배우는 AI 튜터링 웹앱입니다.
나래 선생님(AI)이 소크라테스식 질문으로 아이가 스스로 생각을 발전시키도록 이끕니다.

- 실제로 쓰는 앱(Claude 로그인 필요): https://claude.ai/artifact/PVuT6DGkEADr9nf6cCshPA
- 12년 로드맵 초안(문서): https://claude.ai/artifact/RoPgaaSWQV4J1R1H6fMMgb

## 방향

- **중심:** 문제를 푸는 힘 → 그 힘으로 만드는 힘. 말하는 힘은 과정에서 따라옵니다.
- **생각의 네 걸음:** 문제 파악 → 방법 떠올리기 → 해 보기 → 다시 보기. 아이에게 단계 이름은 말하지 않고, 선생님이 같은 순서로 이끕니다.
- **기다림 3단계:** 막혔을 때 빨리 도와주기 → 보통 → 넉넉히 기다리기. 수업이 쌓이면 자동으로 조절됩니다.

## 기능

| 구분 | 내용 |
| --- | --- |
| 프로필 | 아이 3명까지, 학년·색, 기록 자동 저장과 이어하기 |
| 수업 길 | 교과 탐험(학교 단원 연계), 생각의 길(24칸), 코넌드럼(정답 없는 문제 16개), 자유 탐험, 탈무드 하브루타(선택, 10편), 선생님 되기(역할 바꾸기) |
| 주간 리듬 | 월·수 교과 탐험 · 화·목 생각의 길 · 금 코넌드럼 · 주말 쉼 |
| 수업 | 1~2학년 10분, 3학년 이상 15분, 5분 연장 1회. 끝에 아이가 한 문장으로 정리 |
| 대화 모드 | 블록 스타일 나래 선생님 캐릭터가 말하고(입·날개 움직임), 아이는 버튼을 눌러 말로 대답 |
| 더 하고 싶을 때 | 더 깊이 파기(보너스), 자유 탐험, 하루 최대 횟수(기본 3), 돌다리는 하루 한 칸 |
| 동기 | 생각 배터리 5칸 → 아이가 선물 선택(선생님 옷, 선생님 되기 수업권, 새싹 색) |
| 부모님 | 비밀번호(4자리) 잠금, 전체 기록, 주간 리포트(링크 `#report-프로필id`, PDF 저장) |

## 동작 방식 (중요)

이 앱은 **claude.ai 아티팩트**로 동작하도록 만들어졌습니다. 페이지 안의 `window.claude.use(...)`로 아래 기능을 씁니다.

| 기능 | 쓰는 곳 |
| --- | --- |
| `sample` | 나래 선생님의 대화와 수업 정리(Claude 호출) |
| `db`, `user` | 계정에 기록 저장(아이 기록은 본인만 볼 수 있는 영역) |
| `tts` | 선생님 목소리(지원되지 않는 곳은 기기 한국어 목소리로 대체) |
| `dictation` | 말로 대답하기(Chrome 등) |
| `downloads` | 주간 리포트 PDF 저장 |

그래서 이 저장소의 `index.html`을 GitHub Pages 같은 곳에 그대로 올리면 화면은 열리지만 **AI 대화·계정 저장·목소리는 동작하지 않습니다**(기록은 그 브라우저에만 저장). 독립 웹앱으로 만들려면 Claude API를 부르는 작은 서버가 따로 필요합니다. API 키를 이 HTML 안에 넣으면 안 됩니다.
